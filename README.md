# Task Manager

A small to-do app built with vanilla JavaScript (no dependencies).

## Features

- Add, check off and delete tasks
- Filter: all / to do / completed
- Clear all completed tasks at once
- Automatic saving in the browser (`localStorage`)
- Light/dark theme following the system preference

## Run the project

Just open `index.html` in your browser, or start a local server:

```bash
npx serve .
```
